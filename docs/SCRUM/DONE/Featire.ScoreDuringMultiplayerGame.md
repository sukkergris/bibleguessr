# Display Score During Multiplayer Games

Each player should always be able to see their own score throughout the game.

During the final seven seconds of the countdown, the entire screen should blink with increasing intensity as the timer approaches zero. The warning should feel urgent and stressful without making the game difficult to use or causing discomfort.

If a player does not submit an answer before the time runs out, display the message "Choked!" for that player.
