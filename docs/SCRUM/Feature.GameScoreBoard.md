# Game Scoreboard

The scoreboard should be limited to `The Bible` games and show players ranked by their current scores.

It should have two separate categories:

1. Single-player games
2. Multiplayer games

All-Star scores should be tracked separately for each game type. Single-player All-Star scores must not be combined with multiplayer All-Star scores.

The current scoreboard should reset every 48 hours. When a reset occurs, only the current scoreboard scores should return to zero and a new scoring period should begin. All-Star scores must be preserved.

The scoreboard should display a countdown showing the time remaining until the next reset.
