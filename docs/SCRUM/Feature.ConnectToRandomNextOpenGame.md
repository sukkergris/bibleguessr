# Join the Next Open Multiplayer Game

Users should be able to join the next available multiplayer game automatically.

When a user chooses this option, the system should find an open game and connect the user to it. If no open game is available, the user should see a clear message and be able to try again or start a new game.

The system must not connect users to a game that has a pending invitation for a player who is already connected. That game should remain unavailable for random matchmaking until the invitation is accepted, declined, or cancelled.
