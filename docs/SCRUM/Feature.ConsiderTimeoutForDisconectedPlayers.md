# Remove Disconnected Players After a Timeout

Disconnected players should remain visible for two minutes to allow for a page refresh or a brief network interruption.

After two minutes, the system should remove the player from the room and cancel any pending invitations involving that player.

Disconnected players should be shown in a separate **Offline** section and must not be available for invitations or random matchmaking.

If a player reconnects before the timeout, they should remain in the room and return to the **Online** section.
