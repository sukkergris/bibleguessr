Feature

Social

A standalone area of the app with its own section on the front page. For now it is an empty placeholder.

What the player sees

The front page has a third section, Social, below Singleplayer and Multiplayer. Its Social button opens the Social screen, which so far only says "Coming soon." The usual ← Home button returns to the front page.

Standalone by design

Social lives in its own folder, frontend/src/social/, and may import only from that folder and the shared kernel (frontend/src/shared-kernel/). It never imports from the game types, the multiplayer code or the app shell, so it can grow without getting tangled up in them. frontend/src/social/architecture.test.ts enforces this.

The app shell only knows how to get there: mode-select.ts's GameMode has a { kind: 'social' } case, and bg-app.ts renders <bg-social-home> for its 'social' phase.

Tests

frontend/e2e/social.spec.ts checks the section's place on the front page and the way in and back out.
