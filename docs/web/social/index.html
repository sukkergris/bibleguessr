Feature

Social

A standalone area of the app with its own section on the front page. Its first content is the daily quiz.

What the player sees

The front page has a third section, Social, below Singleplayer and Multiplayer. Its Social button opens the Social screen, which offers Play today's quiz (see Daily quiz). The usual ← Home button returns to the front page.

Standalone by design

Social lives in its own folder, frontend/src/social/, and may import only from that folder, the shared kernel (frontend/src/shared-kernel/) and shared UI (frontend/src/shared-ui/ — the verse card and guess form, which the game uses too). It never imports from the game types, the multiplayer code or the app shell, so it can grow without getting tangled up in them. frontend/src/architecture.test.ts enforces this. Even the server is reached through Social's own small client, and the verse source is handed in by the app shell rather than imported.

The app shell only knows how to get there: mode-select.ts's GameMode has a { kind: 'social' } case, and bg-app.ts renders <bg-social-home> (passing it the verse source) for its 'social' phase. Inside, Social keeps its own explicit view state (home / daily-quiz).

Tests

frontend/e2e/social.spec.ts checks the section's place on the front page and the way in and back out.
