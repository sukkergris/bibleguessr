Feature

Famous verses

A draw from the whole Bible has a 20% chance of picking one of a fixed list of well-known verses, so players meet verses they're likely to recognize more often than pure chance would give them.

Where it applies

DrawFavors famous verses?Where
Daily quiz Yes — each verse of the quiz rolls on its own DailyQuiz.pick (backend/Domain/DailyQuiz.fs)
Singleplayer, "The Bible", server translation Yes GET /api/verses/random with no book parameter (backend/Api/Program.fs)
Multiplayer, "The Bible" Yes pickRandomVerse (backend/Api/GameHub.fs), when GameType.drawsFromWholeBible
Books or chapters chosen No — every verse in play is equally likely Same places
Singleplayer from the player's own file No — that draw happens in the browser frontend/src/bible-sources/local-verses.ts

How a draw works

  1. Roll: a famous draw with FamousVerses:ChancePercent chance, otherwise an ordinary one (FamousVerses.drawKind, an explicit Famous | Any).
  2. A famous draw picks evenly among the famous verses that are in play. If none are (a translation without them, or — in the daily quiz — all of them already drawn), it falls back to an ordinary draw.
  3. An ordinary draw picks evenly among every verse in play, as before.

So the real share of famous verses is a little over the configured chance: the ordinary draw can land on one too. The daily quiz never repeats a verse; a famous draw only considers famous verses not yet drawn that day. The randomness is passed in as a function, so tests make every draw predictable.

The list

FamousVerses.all in backend/Domain/FamousVerses.fs: verses chosen by the maintainer, plus 100 well-known verses Jehovah's Witnesses will recognize. Adding a verse is one line, e.g. famous Book.john 3 16 // Joh 3,16. A verse range is one line per verse, since a draw is one verse. The list holds references only — never verse text.

Numbered as the server's Bible, not as NWT

Like everything the server draws, entries use the bibelen-dk pool's own numbering:

  • Books are numbered by their position in that pool, which is in Lutheran order: Hebrews 58, 1 Peter 59, 2 Peter 60, 1 John 61, James 64. FamousVerses.Book names each number used.
  • A psalm's heading is its verse 1, so NWT's Psalm 83:18 is psalms 83 19.
  • NWT's Joel 2:32 is joel 3 5.

A player playing from their own file (e.g. NWT) resolves a drawn reference by position in their own Bible, so a verse from Hebrews–Jude, or from a psalm with a heading, can resolve to a different verse there. That applies to every drawn verse, not just famous ones, and is not solved yet.

Settings

SettingDefaultMeaning
FamousVerses:ChancePercent 20 The chance, in whole percent (0–100), that a whole-Bible draw is a famous draw. 0 turns the feature off.

Tests

  • backend/Tests/FamousVersesTests.fs — the roll's boundaries, the famous and ordinary pick and its fallback, matching by book number rather than name, no duplicates, and against the real bibelen-dk archive: every Book number is that book's position, and every entry is a verse that exists.
  • backend/Tests/DailyQuizTests.fs — a quiz favors the famous verses, then draws as usual once they're used up, and stays distinct.

The tests can't tell a wrong verse number that still exists (say, 83:18 instead of 83:19) from the right one; every entry was checked by hand against the verse text when it was added — do the same for new ones.
