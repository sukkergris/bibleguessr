Feature

Guess tiles

Players pick the book for a guess from a grid of tiles grouped by testament and category, or with a slider, and the chapter and verse with sliders. The sliders sit in a bar pinned to the bottom of the screen, under a summary of the guess so far. Nothing is typed.

What the player sees

Every guess form (singleplayer and multiplayer) shows the selected Bible's books as tiles, in Bible order, under an Old Testament and a New Testament heading. Within each testament the books are split into categories (Law, History, Poetry & wisdom, Major prophets, Minor prophets, Gospels, Acts, Paul's letters, General letters, Prophecy), each with its own small heading and one of three tile shades.

  • Click a tile to select the book, then guess.
  • Keyboard: focus lands on the first tile for each new verse; the arrow keys move and select, and Enter guesses.
  • In a Books game only the books chosen at setup are shown. In a Chapters game the book is fixed, so the grid is not shown at all.

The guess bar

Below the book grid is the guess bar. It is pinned to the bottom of the screen while the form is in view, so it never scrolls out of reach below the book grid, and always holds, stacked in this order whatever the screen width:

  1. a summary of the guess so far ("Your guess: Rut 3:16"),
  2. a book slider — an alternative to the tiles over the same books in the same order, kept in sync both ways (moving it also scrolls the grid to that book's tile; in a Chapters game the fixed book is shown here instead),
  3. a chapter slider,
  4. a verse slider,
  5. the Guess button.
  • The chapter slider runs over the chosen book's chapters (in a Chapters game, only the chapters chosen at setup — and if only one was chosen, it starts on that chapter, since it is fixed just like the book); the verse slider over the chosen chapter's verses. The current value is shown next to each label.
  • Chapter and verse are optional: the leftmost position is Any, which leaves that part out of the guess, and is where each slider starts. The book slider's leftmost position is "no book".
  • A slider is disabled, with a short reason under it ("Pick a book first.", "Loading chapters…"), until there is something to pick. Picking another book resets the chapter and verse; picking another chapter resets the verse.
  • The slider moves over positions, not the numbers themselves (position 0 is Any, position k the k-th option), so it also works when a Chapters game allows only, say, chapters 3 and 7.
  • The Guess button shares the bottom line with the report buttons fixed in the screen's corners: it is inset by --corner-controls-inline-clearance (see frontend/src/index.css) so they never cover it.
  • The bar sticks within the form, so on a short screen with a long verse it comes into view as soon as the form does, not before.
Names come from the selected Bible

Tile labels are never hardcoded. They are the selected translation's (or the player's own file's) names from VerseSource.getBooksInBibleOrder. Grouping is by book number (position in that list), so it works for any spelling. Only the testament and category headings are app text.

Grouping rules

frontend/src/book-picker.ts holds the category table (BOOK_CATEGORIES, book-number ranges) and the pure function layoutBooks. Ranges, not exact positions, are used so a source that orders books slightly differently within a category still groups correctly. The bundled bibelen-dk, for example, places Jakob after 3. Johannes, and both still fall in General letters (59–65).

If a source does not have exactly STANDARD_CANON_BOOK_COUNT (66) books, for example one that includes deuterocanonical books, the grid falls back to a single ungrouped list in Bible order rather than showing wrong headings.

No jumping between verses

  • While the next verse loads, the verse card keeps the height it had (see frontend/src/components/verse-card.ts) instead of collapsing to one line, and the previous verse is no longer shown — or guessable — meanwhile.
  • A new guess form is created for every verse. The book list is cached per source and translation, so the new form shows its full grid straight away instead of starting empty and growing once the list has loaded.
  • A slider's "why disabled" hint is laid over the slider instead of taking a line of its own, so it appearing and disappearing (e.g. "Loading chapters…") never changes the bar's height.
  • Covered by frontend/e2e/next-verse-stability.spec.ts, which adds latency to the API and measures both heights on every frame.

Accessibility

  • Tiles are native radio buttons inside nested <fieldset>s, so the testament and category names are announced as group names; Tab enters the group once and the arrow keys move and select. Tab then moves on to the book slider, the chapter slider, the verse slider and the Guess button — the same order as on screen. Enter on any tile or slider submits the guess. In a Chapters game focus starts on the chapter slider.
  • The sliders are native <input type="range"> with a visible label. Because they move over positions, each sets aria-valuetext ("Any chapter", "Chapter 12") so a screen reader announces the real book, chapter or verse; the reason a slider is disabled is linked with aria-describedby. On narrow screens each label moves above its slider so the slider keeps a usable width.
  • The summary is deliberately not a live region: each tile and slider already announces its own new value, so announcing the summary too would say everything twice.
  • The selected tile has an accent fill, a bold name and a ✓ mark. The category shades are backed by visible text headings. Neither state nor category is conveyed by colour alone.
  • The shades are theme tokens (--tile-1..3, --tile-text in frontend/src/index.css), all above 4.5:1 against the tile text in both themes. Focus uses the shared --focus outline.
  • The book grid scrolls inside a capped-height box, and every tile is at least 2.75rem tall as a comfortable touch target.

Implementation and tests

The grid lives in frontend/src/components/guess-form.ts (_renderBookPicker and _renderSlider). They replaced the free-text comboboxes and the Books/Chapters-mode <select>s. A guess can now only name a book, chapter and verse that exist in the player's own Bible.

Grouping is unit tested in frontend/src/book-picker.test.ts. The grids' behaviour (grouping, tiles and book slider in sync, chapter/verse scoping and resets, stacking order, the pinned bar, keyboard operation) is covered by frontend/e2e/book-picker.spec.ts.
