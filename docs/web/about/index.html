Feature

About

A static screen telling players what BibleGuessr is, how their own Bible file stays private, and where the bundled Bible text comes from.

What the player sees

The front page's last section, About, comes after Social. Its About button opens the About screen at /about, with four short parts: the game, the privacy of the player's own Bible file, the Bible text (the public-domain Danish 1933 Bible, credited to Project Runeberg), and the project's MIT license. The usual ← Home button returns to the front page.

How it fits in

mode-select.ts's GameMode has an { kind: 'about' } case, and routes.ts maps it to the /about address (see Links and navigation). bg-app.ts renders <bg-about-page> for that address. The page is indexable: it is in INDEXABLE_ROUTES and frontend/public/sitemap.xml (see SEO).

The text about Bible translations is a short summary of NOTICE.md. When the bundled translations change, update both.

Tests

frontend/e2e/about.spec.ts checks the section's place on the front page, the way in and back out, and opening /about directly. The route and page metadata are covered by frontend/src/routing/routes.test.ts and frontend/src/routing/page-meta.test.ts.
