Feature

About

A static screen telling players what BibleGuessr is, how their own Bible file stays private, and where the bundled Bible text comes from.

What the player sees

The front page's last section, About, comes after Social. Its About button opens the About screen at /about, with five short parts: the game, the privacy of the player's own Bible file, the Bible text (the public-domain Danish 1933 Bible, credited to Project Runeberg), the project's MIT license, and Nerd stuff — how to open the nerd panel: the connection menu's Nerd panel button, or Alt+Shift+N (see Keyboard shortcuts). The usual ← Home button returns to the front page.

How it fits in

mode-select.ts's GameMode has an { kind: 'about' } case, and routes.ts maps it to the /about address (see Links and navigation). bg-app.ts renders <bg-about-page> for that address. The page is indexable: it is in INDEXABLE_ROUTES and frontend/public/sitemap.xml (see SEO).

The text about Bible translations is a short summary of NOTICE.md. When the bundled translations change, update both.

The Nerd stuff section is where a player learns the nerd panel exists. It renders the shortcut from NERD_PANEL_SHORTCUT_KEYS in frontend/src/nerd-panel-control.ts, so a new shortcut shows up here by itself; the sentence about the Option key on a Mac assumes it uses Alt.

Tests

frontend/e2e/about.spec.ts checks the section's place on the front page, the way in and back out, opening /about directly, and that the Nerd stuff section names the shortcut and the Nerd panel button, and the shortcut opens the panel from there. The route and page metadata are covered by frontend/src/routing/routes.test.ts and frontend/src/routing/page-meta.test.ts.
