Feature

Keyboard shortcuts

The Nerd Panel documents the application's keyboard shortcuts, so they can be discovered without reading the console or the source.

The guide

A Keyboard shortcuts section sits at the top of the Nerd Panel, above the version diagnostics, so user-facing guidance and developer information stay distinguishable. Shortcut and action pairs are a real definition list, so screen readers can navigate them as pairs rather than as loose text.

Only implemented shortcuts are listed. Today that is one: Alt + Shift + N, which shows or hides the panel. On a Mac, Alt is the Option key; the guide says so.

The panel can't describe a shortcut to someone who hasn't opened it yet, so the About page's Nerd stuff section names this one too.

Why Alt+Shift+N

The shortcut used to be Ctrl + Shift + N. Chrome and Edge on Windows open a private window on that combination before the page ever sees it, so on the most common setup the panel could not be opened at all. Alt + Shift + N is not taken by the major browsers or by Windows itself (Windows switches keyboard layout on Alt+Shift alone, not with a letter).

The shortcut follows the letter a key types, so it works on any keyboard layout. On a Mac, Option+Shift+N types a symbol rather than an N, so when the key doesn't report a letter the physical N key counts instead. With Ctrl or Cmd held as well, it is some other shortcut and is left alone.

Not the only way in

A shortcut is a convenience here, never the only way in or out. The connection menu (the dot in the top-right corner) has a Nerd panel button, which works without a keyboard and moves focus into the panel — see Connection status. The panel's Close button closes it, and focus goes back to where it was when the panel opened. The guide points at both.

A closed panel is inert as well as aria-hidden: it is only narrowed to nothing, so without inert its controls would still take Tab stops.

Not while typing

The shortcut is ignored when the key event originates in an input, textarea, select, or content-editable element, so it cannot interrupt a chat message or a name being entered. This is checked through the event's composed path rather than document.activeElement, which only reports the shadow host when focus is inside a component.

Toggling is idempotent: repeated activation only shows or hides the one panel, and never creates duplicates or duplicate listeners.

Implementation

frontend/src/nerd-panel-control.ts defines the shortcut (its keys, and isNerdPanelShortcut, unit-tested in nerd-panel-control.test.ts) and the open request the connection menu sends. frontend/src/components/nerd-panel.ts owns the shortcut handler, the typing guard, focus handling and the guide. Coverage of the guide's content, the toggle, the old chord no longer working, the inert closed panel, repeat activation, semantic structure, keyboard close, and non-interference with typing is in frontend/e2e/nerd-panel-shortcuts.spec.ts; opening from the connection menu is in frontend/e2e/nerd-panel-connection-menu.spec.ts.
